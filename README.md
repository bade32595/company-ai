# AI Company Profile Studio

واجهة عربية RTL تعمل في المتصفح باستخدام HTML5 وCSS3 وJavaScript.

## التشغيل
افتح index.html في متصفح حديث واتصل بالإنترنت لتحميل المكتبات من CDN. إذا واجهت قيوداً في فتح الملفات محلياً، استخدم Live Server في Visual Studio Code.

## النشر على Vercel
استورد المستودع في Vercel باعتباره Static Site. لا يتطلب Build Command، ومجلد الإخراج هو جذر المستودع.

## مزودو الذكاء الاصطناعي
يدعم النموذج الواجهة اختيار OpenAI وAnthropic Claude وGoogle Gemini، ويجب إدخال مفتاح API صالح من المزود المختار. قد تختلف النماذج المتاحة حسب صلاحيات حسابك. اتصالات المزودين في النسخة الثابتة تتم من المتصفح مباشرةً.

## الأمان
مفاتيح API في الواجهة للتجربة فقط؛ لا تضع مفتاح إنتاجي في تطبيق عام. استخدم Cloudflare Worker/Backend وخزّن المفاتيح كمتغيرات سرية قبل إتاحة الذكاء الاصطناعي للجمهور.

## ملاحظات
- PDF.js يستخرج النصوص من PDF المرفوع كمصدر، كما يحوّل صفحات PDF في قسم صور المشاريع إلى صور معاينة قابلة للإدراج في PowerPoint (حتى 12 صفحة لكل ملف).
- Mammoth.js يستخرج النصوص من DOCX وSheetJS يقرأ ملفات Excel.
- الوضع المحلي ينشئ مسودة أولية وليس نموذج ذكاء اصطناعي كاملاً.
- راجع ملف PPTX في PowerPoint، خاصة اتجاه النص العربي وتوفر خط Sakkal Majalla.


## توليد محتوى احترافي وقوالب التصميم
- عند إدخال مفتاح API صالح، يوسّع الذكاء الاصطناعي حتى النبذة القصيرة إلى قصة شركة منظمة، مع توجيهات تمنع اختلاق الحقائق.
- يُعامل البروفايل والملفات المرجعية بوصفها المصدر الأساسي؛ يحافظ على الأسماء والصياغات الرسمية والمعلومات المهمة، ويدمج الحقائق المتكررة دون إعادة تكرارها.
- يمكن إرسال أول أربع صور/صفحات مشروع إلى نموذج متعدد الوسائط لتحليلها بصرياً؛ وتُدرج الصور الأخرى المتبقية كشرائح صور عند توفر مساحة في عدد الشرائح.
- تتضمن المعاينة خمسة قوالب أصلية قابلة للاختيار: Premium Executive وModern Minimal وBold Corporate وEditorial Luxury وTech Modern.
- مولّد PPTX يستخدم مكتبة PptxGenJS مفتوحة المصدر بترخيص MIT: https://github.com/gitbrent/PptxGenJS
- مكتبات القوالب الخارجية ليست كلها قابلة لإعادة التوزيع داخل تطبيق عام. مثلاً، تسمح SlidesCarnival بالاستخدام والتعديل مع الإسناد وفق CC BY 4.0: https://www.slidescarnival.com/terms-of-use/ . أما شروط Slidesgo فتقيّد إدراج محتواها في قواعد بيانات أو مكتبات على الإنترنت أو خارجها: https://slidesgo.com/terms-conditions . لذلك القوالب المدمجة هنا تصميمات أصلية بدلاً من إعادة توزيع ملفات قوالب خارجية.
